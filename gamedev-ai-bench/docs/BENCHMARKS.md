# Benchmark execution

## Browser

`web-orbit` is the currently enabled original browser task: collect nine cells, avoid hazards, offer start/pause/restart, keyboard and touch controls. The remaining three browser briefs cover checkpoint regression, responsive input and a lightweight world; their paid execution is blocked until semantic, task-specific assertions and baselines are qualified.

The worker takes a persistent lease, verifies its frozen configuration hash, confirms isolation availability, and calls exactly one native provider generation endpoint. The model must return bounded JSON containing local UTF-8 project files. No install scripts, dependency downloads or CDNs are run. Invalid output produces observed failed assertions and a zero technical score, rather than a fictional playable game.

Generation, browser inspection and administrative review are separate stages. Provider timeout outcomes can be financially uncertain and are not automatically retried. Use a new explicitly authorized campaign after investigating a failure.

Artifacts include the generated project, evaluation report, desktop/mobile screenshots where available, a private frozen configuration, and private supplier response/usage. SHA-256 identities are checked before reads/publication. Missing evidence is not repaired with invented logs or screenshots.

## Fixture qualification

The orbital and meadow fixtures are authored by this project, not sampled from model APIs. Both implement the same collect-nine brief with different visual directions. They test the player, voting and pipeline without API charges. Their results must remain `fixture=true`. Temporary automated review test records must never be copied into production.

## Roblox

See `apps/roblox-runner/scenarios/`: ten original generators for obby, checkpoints, inventory, RemoteEvent authority, rewards, UI, regression, world construction, multiplayer and a complete-game starting baseplate. Repair fixtures intentionally contain defects and must never be published unchanged as a live game. Pure-module contracts are executable Luau but were not executed in Studio in this environment. Respawn, replication, multi-client behavior and subjective spatial quality need real Studio evidence.

The local MCP runner executes owner-approved plans and uploads receipts; it does not claim receipt equals a benchmark score. Automated paid agent execution for Studio remains blocked rather than simulated.
